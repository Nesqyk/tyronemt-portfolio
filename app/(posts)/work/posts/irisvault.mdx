# IrisVault

Privacy-first desktop runtime enabling secure, low-latency screen and audio context for local AI agents.

## Overview

A local foundation for secure, context-aware assistant workflows.

## Problem

Teams need responsive screen and audio context without losing control of sensitive data.

## Approach

The runtime manages local context flow and limits what data leaves the host machine.

## Role

Product direction, systems design, and full-stack development.
