# Applymatic

An automation extension that drafts context-aware application responses using saved profile data.

## Overview

A browser extension for reducing repetitive application workflows.

## Problem

Long application forms require repeated, inconsistent manual responses.

## Approach

The extension maps field intent to saved profile data while preserving a mandatory human review before submission.

## Role

Product strategy, UX, and full-stack development.
